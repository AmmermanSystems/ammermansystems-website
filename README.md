# Ammerman Systems LLC — Website

Official company website for [ammermansystems.com](https://ammermansystems.com).

**Motto:** *Fides et Ingenium* — Trust and Ingenuity

Static single-page site (HTML/CSS/JS) prepared for GitHub Pages. The live site and custom-domain DNS must not be enabled until the owner approves.

## Local preview

```bash
cd docs
python3 -m http.server 8080
```

Open `http://127.0.0.1:8080/`.

## Structure

| Path | Purpose |
| --- | --- |
| `docs/index.html` | Page markup + SEO meta |
| `docs/styles.css` | Layout, theme, responsive styles |
| `docs/script.js` | Nav toggle + reveal motion |
| `docs/favicon.svg` | Favicon |
| `docs/og-image.svg` | Social share image |
| `docs/CNAME` | Custom domain hint for Pages (post-approval) |
